# Changelog

## 0.5.0 — first public beta

- Installable GitHub release and browser-accessible no-key demonstration.
- `doctor`: real local Chromium launch; optional Claude CLI flag preflight.
- `init`: explicit text goals, preserved text, independent brief and confirmation
  flags make simple acceptance capture possible without JSON authoring.
- `share`: portable HTML/JSON summaries from explicit fields; private source,
  prompts, paths and raw receipts excluded. Intent/screenshots are opt-in.
- Stopped candidate arms now retain inconclusive baseline comparison rows.
- English/Korean onboarding, contribution guidance, data boundaries and CI.

## Pre-release 0.4

Source-blind reconstruction, purpose/preservation checks, independent JSON inputs,
three-way workflow comparison and documented trials on three existing projects.

## Pre-release 0.3

Persistent problem library, source snapshots, catalog observation, budgeted
queues, durable attempts and reconciliation without replay.

## Pre-release 0.1–0.2

Static artifact capture, independent checks, context projection, tool-free
generation, bounded accounting and portable browser evidence.
